Política de Privacidad

Última actualización: 2026. Al usar Tentakul aceptas lo aquí descrito.

1. Qué recopilamos

Los datos que nos das para crear tu cuenta y usar el servicio: tu correo, los datos de tu negocio (marca, rubro, productos) y las métricas que decides conectar (Google Analytics, tu tienda, publicidad). No pedimos más de lo necesario.

2. Para qué los usamos

  • Darte el servicio: generar contenido, simulaciones y reportes.
  • Mostrarte tus propias métricas dentro de la app.
  • Mejorar Tentakul y darte soporte.

3. Datos de Google (API Services)

El uso que Tentakul hace de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado. Solo leemos las métricas que autorizas, únicamente para mostrártelas dentro de Tentakul; no las vendemos ni las usamos para publicidad.

4. Tus clientes

La lista de clientes que importas o conectas es tuya. Tentakul la usa solo para darte el servicio (CRM, mapa de zonas, simulaciones). No la compartimos con terceros.

5. Tus derechos

Puedes pedir acceso, corrección o eliminación de tus datos cuando quieras, escribiéndonos.

6. Contacto

Dudas o solicitudes: hola@tentakul.com
